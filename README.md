# Inno Cat: публикация на pr.innocats.ru через GitHub Pages

1. Создайте новый публичный репозиторий innocat-pr в своём аккаунте GitHub.
2. Загрузите всё распакованное содержимое архива в корень репозитория.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Проверьте, что Custom domain содержит pr.innocats.ru.
5. В DNS домена innocats.ru замените существующий CNAME для pr:
   старое значение custom-domains.chatgpt.site.
   новое значение vespaasya.github.io.
   Основные записи @ и www менять не нужно.
6. После проверки DNS и выпуска сертификата включите Enforce HTTPS.
7. Проверьте адрес https://pr.innocats.ru/ на телефоне с VPN и без VPN.

Фото, оформление, кнопки и шрифты включены в архив.
Страница не зависит от OpenAI Sites. Google Форма и Telegram остаются внешними
сервисами, их доступность определяется сетью посетителя.
Закрытый кабинет и база данных не входят в эту публичную страницу.
